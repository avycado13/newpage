# NewPage
A beautiful new tab page that shows a picture from NASA each day.

## Usage
Go [here](https://avycado13.github.io/newpage)

## Features
- Updated Image from NASA image of the day everyday (subject to nasa publishing one)
- Hideable Description of Image
- DuckDuckGo Searchbar


## Development
1. run `bun install`
2. To Get a hot reload dev server run `bun run dev`
3. To build run `bun run build`
